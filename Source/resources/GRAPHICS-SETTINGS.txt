Edit catherine-settings.ini beside Catherine.exe, under [Catherine], then restart.

ShowFps=false
Upscaler=off
UpscaleQuality=quality
FsrSharpness=20
FrameGeneration=off
FrameGenerationMultiplier=4

Set Upscaler=fsr1 for AMD FSR 1. Quality choices: ultraquality, quality,
balanced, performance. Sharpness: 0-100. Set ShowFps=true to show the counter.

Set FrameGeneration=dlssg for experimental NVIDIA DLSS Frame Generation on
Windows. Keep the supplied Streamline folder beside the executable. The GPU
limits the requested 2x/3x/4x multiplier. Loading/video frames use normal
presentation. Missing/unsupported features fall back to normal rendering.

Fps caps rendered frames. For a 240 FPS target with 4x generation, use Fps=60.
The counter shows actual presented FPS and rendered FPS when generation runs.

Upscaling, frame generation, and the FPS counter all default off. DLSS Super Resolution is not implemented.
